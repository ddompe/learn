## Por qué importa

Todo lo que vas a automatizar es un **programa**: una lista de instrucciones que una
computadora sigue al pie de la letra. Si puedes leer un programa corto, puedes revisar
lo que un asistente de IA escribió para ti. Todavía no necesitas escribir programas.
Primero se aprende a leer.

<CaseStudy>
	La rutina mensual de Daniela, en su cabeza, es una lista de pasos: abrir el
	archivo, contar las filas, revisar el total. Un programa es esa misma lista,
	escrita con tanta precisión que una computadora puede seguirla.
</CaseStudy>

## Código fuente

El **código fuente** es un programa escrito como texto en un **lenguaje de
programación**. Se guarda en un archivo de texto plano, como un CSV, pero con reglas
distintas. Python es el lenguaje que usa este curso. Un archivo de Python termina en
`.py`.

El procesador de una computadora no puede leer Python directamente. Solo entiende
instrucciones de muy bajo nivel. Alguien tiene que traducir.

## Intérpretes y compiladores

Existen dos tipos de traductores.

- Un **compilador** traduce todo el programa por adelantado a un archivo que el
  procesador puede ejecutar directamente. Luego ejecutas ese archivo. Lenguajes como C y
  Rust funcionan así.
- Un **intérprete** lee el código fuente y lleva a cabo las instrucciones sobre la
  marcha, línea por línea. Python funciona así.

<Mermaid

Con Python conservas el archivo fuente y se lo das al intérprete cada vez. Por eso
puedes leer, cambiar y volver a ejecutar un programa con rapidez. También por eso
necesitas tener Python instalado para ejecutar el programa de Python de otra persona
(lección 4.2).

## Lee un primer programa

<Example file="part03/01_program.py" />

Léelo de arriba hacia abajo:

1. Una línea que empieza con `"""` es un **docstring**, una nota que describe el
   programa.
2. `from pathlib import Path` toma prestada una herramienta para trabajar con rutas de
   archivo (lección 1.4).
3. `sales_file = ...` guarda la ubicación del archivo de ventas con el nombre
   `sales_file`. Un nombre que guarda un valor es una **variable**.
4. `lines = ...` lee el archivo y lo divide en una lista de líneas.
5. `print(...)` muestra un mensaje. El programa informa 246 filas: las 240 ventas más
   seis líneas repetidas. Resta una por el encabezado.

No necesitas recordar la sintaxis. Lo importante es que cada línea hace una sola cosa y
tú puedes decir cuál.

## Errores comunes

- **Pensar que debes memorizar la sintaxis.** Primero se aprende a leer. Los asistentes ayudan a escribir.
- **Confundir el programa con su resultado.** El archivo `.py` contiene instrucciones. La salida aparece cuando lo ejecutas.
- **Editar un programa en Word.** Usa un editor de código (lección 3.2). Word añade formato oculto.
- **Tratar los errores como un fracaso.** Un mensaje de error es la computadora diciéndote lo que no pudo hacer.
