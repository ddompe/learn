La Parte 3 establece los hábitos de trabajo de un ingeniero de software: un editor de
código, un asistente de IA cuyo trabajo revisas, control de versiones, manejo seguro de
secretos y una primera mirada a las pruebas y los errores. Aquí instalas VS Code y Git.
Python llega en la Parte 4.
