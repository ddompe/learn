## Por qué importa

La lección 1.4 mostró que las rutas difieren entre sistemas y que una ruta relativa
depende de dónde estás parado. Las rutas armadas a mano como texto, por ejemplo
`"C:\\Users\\..."`, se rompen en el momento en que un colega ejecuta el programa. El
módulo `pathlib` resuelve esto: describes una ruta por piezas y él la escribe
correctamente para el sistema.

<CaseStudy>

	cuando una tarea programada lo inicia desde otro lugar. La solución es
	encontrar los datos en relación con el propio script.
</CaseStudy>

## Objetos de ruta

```text
from pathlib import Path

data_dir = Path("data")
sales = data_dir / "cafe_central_sales.csv"
```

El operador `/` une las piezas con el separador correcto para el sistema. Partes y
acciones útiles:

| Expresión              | Significado                                    |
| ---------------------- | ---------------------------------------------- |
| `path.name`            | Nombre del archivo con extensión               |
| `path.suffix`          | La extensión, como `.csv`                      |
| `path.parent`          | La carpeta que lo contiene                     |
| `path.exists()`        | Si existe                                      |
| `path.read_text(...)`  | Leer todo el archivo como texto                |
| `path.write_text(...)` | Escribir texto en el archivo                   |
| `folder.glob("*.csv")` | Encontrar archivos que coinciden con un patrón |

Pasa siempre `encoding="utf-8"` al leer o escribir texto, para que las tildes
sobrevivan (lección 1.7).

## Encuentra archivos en relación con el script

`Path(__file__)` es la ubicación del script en ejecución. A partir de ella puedes llegar a
otros archivos sin importar cuál sea la carpeta actual.

## Errores comunes

- **Escribir rutas como texto con barras invertidas.** Usa `Path` y `/`.
- **Depender de la carpeta actual.** Ancla las rutas a `__file__`.
- **Olvidar la codificación.** Añade `encoding="utf-8"`.
- **Sobrescribir un archivo de entrada.** Escribe los resultados en otro archivo u otra carpeta.
- **Usar en código compartido rutas absolutas de tu propia máquina.**

## Compruébalo tú mismo

<Checkpoint question="¿Qué hace el operador / en los objetos Path?">
	Une las piezas de una ruta con el separador correcto para el sistema.
</Checkpoint>

<Checkpoint question="¿Por qué anclar las rutas a `__file__`?">
	Para que el programa encuentre sus archivos sin importar desde qué carpeta se
	inicie.
</Checkpoint>

<Checkpoint question="¿Por qué pasar la codificación a read_text?">
	Para que las tildes se lean y se escriban correctamente, en lugar de depender
	del valor predeterminado del sistema.
</Checkpoint>
