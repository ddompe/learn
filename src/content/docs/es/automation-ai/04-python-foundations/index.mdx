En la Parte 4 ejecutas Python por primera vez. Lo instalas con uv, creas un proyecto y
aprendes las ideas centrales: tipos, texto, colecciones, decisiones, funciones, archivos
y errores. La parte termina con un pequeño script con pruebas para las ventas de Café
Central.
