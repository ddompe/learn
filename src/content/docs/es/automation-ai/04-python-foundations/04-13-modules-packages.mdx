No escribes todo tú mismo. Leer archivos CSV, contar, manejar fechas y trabajar con

## Módulos y paquetes

Un **módulo** es un archivo de código de Python que puedes reutilizar. Un **paquete** es
una colección de módulos, distribuida a través de un registro (lección 3.8).

- La **biblioteca estándar** son los módulos que vienen con Python: `csv`, `pathlib`,
  `decimal`, `datetime`, `collections` y muchos más. No necesitan instalación.
- Los **paquetes de terceros** se instalan desde PyPI con `uv add`: por ejemplo `pandas`.

## Importar

```text
import csv
from collections import Counter
import pandas as pd
```

- `import csv` deja disponible el módulo como `csv`.
- `from collections import Counter` toma un nombre de un módulo.
- `import pandas as pd` da un apodo corto. `pd` es el apodo universal de pandas.

## Añadir un paquete de forma segura

1. Decide si lo necesitas. ¿La biblioteca estándar ya hace el trabajo?
2. Comprueba el nombre exacto en PyPI (lección 3.8): responsables, historial de versiones, enlaces.
3. Ejecuta `uv add nombre` dentro del proyecto.
4. Haz commit de `pyproject.toml` y `uv.lock`.

Si obtienes `ModuleNotFoundError`, el paquete no está en el entorno que estás usando.
Ejecuta el programa con `uv run` y comprueba que el paquete esté en `pyproject.toml`.

## Errores comunes

- **Ponerle a tu propio archivo el nombre de un módulo.** Un archivo llamado `csv.py` oculta el `csv` real.
- **Instalar con pip.** Usa `uv add`.
- **Importar todo con `*`.** Oculta de dónde vienen los nombres.
- **Añadir un paquete para un trabajo minúsculo.** Cada uno es una dependencia que mantener.
- **No hacer commit del archivo de bloqueo.**
