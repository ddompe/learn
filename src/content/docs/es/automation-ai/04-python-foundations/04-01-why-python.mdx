## Por qué importa

Vas a pasar el resto del curso escribiendo y leyendo Python. Ayuda saber por qué lo
elegimos, para que no parezca una regla arbitraria. También ayuda en las conversaciones
con colegas que prefieren otras herramientas.

<CaseStudy>
	El equipo de Daniela tiene Excel, Power Query y algunas macros. Cuando
	necesita combinar cientos de archivos, o llamar a un servicio de IA, esas
	herramientas se quedan cortas. Python es la herramienta que la mayoría de las
	personas en su posición aprende después.
</CaseStudy>

## Una historia breve

Guido van Rossum empezó Python a finales de la década de 1980 y lo publicó en 1991. Lo
diseñó para que fuera fácil de leer y para que una persona pudiera decir mucho en pocas
líneas. El nombre viene del grupo de comedia Monty Python, no de la serpiente.

Desde entonces, tres cosas lo convirtieron en el lenguaje predeterminado para trabajar
con datos:

1. **Legibilidad.** El código de Python se parece al inglés sencillo. Un principiante
   puede leer un programa corto y adivinar qué hace.
2. **Baterías incluidas.** La biblioteca estándar cubre archivos, fechas, texto, CSV y
   mucho más sin descargas adicionales.
3. **Un ecosistema enorme.** Existen miles de paquetes gratuitos para datos (pandas),
   gráficos (matplotlib), documentos, la web y aprendizaje automático. Casi toda
   herramienta de IA ofrece primero una interfaz en Python.

## Por qué importa para la IA

La mayoría de las bibliotecas y servicios de IA se escriben primero para Python, y la
mayoría de los ejemplos que encuentras en línea están en Python. Los asistentes de IA
también han visto mucho más Python que la mayoría de los lenguajes, así que lo escriben
bien. Es una razón práctica: obtienes la mejor ayuda.

## Ventajas y desventajas

Python no es lo mejor en todo.

- **Velocidad.** Python es más lento que lenguajes como C o Rust para cálculos pesados.
  Las bibliotecas lo disimulan haciendo el trabajo pesado en código rápido por debajo.
  Para datos de negocio, rara vez es un problema.
- **Aplicaciones móviles y interfaces web.** Otros lenguajes dominan ahí.
- **Versiones e instalaciones.** Configurar mal Python causa muchos dolores de cabeza. Por
  eso la lección 4.2 usa uv.

## Errores comunes

- **Tratar a Python como la única opción.** Es un buen punto de partida, no una ley.
- **Comparar velocidades sin contexto.** Para un informe mensual, un segundo más o menos no importa.
- **Empezar sin una configuración clara.** La lección 4.2 evita los problemas típicos.
- **Pensar que debes memorizar la sintaxis.** Leerás mucho más de lo que escribirás.
