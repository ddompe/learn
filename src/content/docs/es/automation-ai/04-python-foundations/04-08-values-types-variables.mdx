## Por qué importa

En Excel, una celda puede parecer un número y ser en secreto texto, y entonces una suma
sale mal. Python tiene el mismo problema, pero es más estricto y más claro al respecto.
Lo primero que debes saber de cualquier valor es su **tipo**: qué clase de cosa es y, por
lo tanto, qué puedes hacer con él.

<CaseStudy>
	Todo lo que Daniela lee del CSV de ventas llega como texto, incluidos los
	montos. Si suma dos montos sin convertirlos, une el texto en lugar de sumar
	los números.
</CaseStudy>

## Variables

Una **variable** es un nombre que apunta a un valor. La creas con `=`:

```text
amount = 2200
```

Léelo como "sea `amount` igual a 2200", no como una ecuación. Puedes cambiarla después.
Elige nombres que digan qué es el valor: `amount` es mejor que `x`.

## Los tipos comunes

| Tipo     | Nombre en Python | Ejemplo           | Uso                                 |
| -------- | ---------------- | ----------------- | ----------------------------------- |
| Texto    | `str`            | `"jugo"`          | Palabras, ID, contenido de archivos |
| Entero   | `int`            | `7`               | Conteos                             |
| Float    | `float`          | `7.5`             | Mediciones, con pequeños errores    |
| Decimal  | `Decimal`        | `Decimal("7.50")` | Dinero exacto (lección 1.8)         |
| Booleano | `bool`           | `True`, `False`   | Respuestas de sí o no               |
| Nada     | `NoneType`       | `None`            | "Aquí no hay valor"                 |

`type(value)` te dice el tipo.

## Los tipos deciden qué significan las operaciones

<Example file="part04/08_types.py" />

La línea `Text plus text` muestra la trampa: `"2200.00" + "2200.00"` da
`2200.002200.00`. Para el texto, `+` significa "unir". Después de convertir a `Decimal`,
el mismo `+` significa "sumar" y el resultado es `4400.00`.

<Mermaid
	diagram={`flowchart LR
  A["Texto del archivo: '2200.00'"] -->|"Decimal(...)"| B["Número exacto: 2200.00"]
  B --> C["La aritmética funciona"]`}
/>

Para convertir, usa el nombre del tipo como una función: `int("7")`, `float("7.5")`,
`Decimal("7.50")`, `str(7)`.

Si el texto no es válido para el tipo, Python se detiene con un error, lo cual es mejor
que sumar números equivocados en silencio.

## Errores comunes

- **Hacer aritmética con texto.** Convierte primero.
- **Usar floats para dinero.** Usa `Decimal` (lección 1.8).
- **Usar un nombre demasiado corto o poco claro.**
- **Reutilizar el nombre de una variable para otra cosa.** Hace el código más difícil de seguir.
- **Mezclar `=` y `==`.** Uno asigna y el otro compara (lección 4.11).
