## Por qué importa

Escribir Python solo sirve si puedes ejecutarlo. Hay tres formas comunes, cada una para
un trabajo distinto. Saber cuál usar te evita copiar código entre herramientas y
preguntarte por qué los resultados difieren.

</CaseStudy>

## El REPL

El **REPL** (read, evaluate, print, loop: leer, evaluar, imprimir, repetir) es una
consola interactiva. Escribes una línea, Python la ejecuta y muestra el resultado. Es una
calculadora para código.

```text
uv run python
```

El prompt cambia a `>>>`. Prueba:

```text
>>> 2200 + 1500 + 1400
5100
>>> exit()
```

Usa el REPL para probar una idea pequeña. No se guarda nada cuando sales.

## Ejecuta un script

Un **script** es un archivo de Python que ejecutas de principio a fin. Aquí está el
primero:

<Example file="part04/04_hello.py" />

Desde la carpeta del proyecto, ejecuta:

```text
uv run python 04_hello.py
```

`uv run` se asegura de que el programa se ejecute dentro del entorno del proyecto
(lección 4.3), con el Python y los paquetes correctos. Inicia siempre los programas con
`uv run`.

## Ejecuta en VS Code

1. Instala la extensión **Python** (del publicador Microsoft) en VS Code.
2. Abre el archivo. Si VS Code pide un intérprete, elige el que está en `.venv` dentro de tu proyecto.
3. Haz clic en el triángulo **Run** (Ejecutar) arriba a la derecha del editor. La salida aparece en la terminal de abajo.

El botón Run hace lo mismo que el comando de la terminal. Usa cualquiera de los dos y
fíjate en que ambos muestran la misma salida. Si difieren, uno de ellos está usando un
entorno distinto.

## Errores comunes

- **Ejecutar `python` en lugar de `uv run python`.** Puede iniciarse el Python equivocado.
- **Ejecutar desde la carpeta equivocada.** El nombre del archivo es relativo a la carpeta actual.
- **Editar un archivo y olvidar guardarlo.** Se ejecuta la versión vieja.
- **Escribir líneas de código que empiezan con `>>>`.** Eso es el prompt, no parte del código.
- **Esperar que el REPL recuerde.** Al cerrarlo olvida todo.
