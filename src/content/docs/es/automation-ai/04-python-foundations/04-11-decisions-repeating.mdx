## Por qué importa

La automatización consiste sobre todo en dos ideas: hacer algo con cada elemento y hacer
cosas distintas según el elemento. En Excel, son el relleno hacia abajo y `SI`. En
Python, son `for` e `if`. Con estas dos y las colecciones de la lección 4.10, puedes
procesar un archivo completo.

	cuántas ventas hacen falta para superar una meta diaria.
</CaseStudy>

## Decisiones: if

```text
if amount >= 5000:
    label = "large"
elif amount >= 1500:
    label = "medium"
else:
    label = "small"
```

Python revisa las condiciones en orden y ejecuta el primer bloque que sea verdadero. Las
líneas dentro de un bloque están **sangradas** (indentadas, movidas a la derecha cuatro
espacios). La sangría es cómo Python sabe qué pertenece a qué, así que importa.

Las comparaciones dan un booleano: `==` igual, `!=` distinto, `<`, `>`, `<=`, `>=`.
Combínalas con `and`, `or` y `not`.

## Repetir: for y while

Un bucle `for` se repite una vez por cada elemento de una colección. Un bucle `while` se
repite mientras una condición siga siendo verdadera.

<Example file="part04/11_control_flow.py" />

El bucle `for` visita cada monto y decide su etiqueta. El bucle `while` sigue sumando
ventas a un total acumulado hasta que pasa de 5000. Se detiene después de 3 ventas, en 5100.

<Mermaid
	diagram={`flowchart TD
  A["Inicio: running = 0"] --> B{"¿running < 5000?"}

Un bucle `while` necesita algo dentro que, tarde o temprano, haga falsa la condición. Si
no, se ejecuta para siempre. Detén un programa descontrolado con **Ctrl+C** en la
terminal.

## Errores comunes

- **Sangría incorrecta.** Una línea con demasiada o muy poca sangría cambia el significado.
- **Usar `=` en lugar de `==` en una condición.** Uno asigna y el otro compara.
- **Cambiar una lista mientras haces un bucle sobre ella.** Haz una lista nueva.
- **Un bucle `while` que nunca termina.** Asegúrate de que la condición pueda volverse falsa.
- **Revisar las condiciones en el orden equivocado.** En `if`/`elif`, pon primero la condición más estrecha.
