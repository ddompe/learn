## Por qué importa

Los datos de negocio vienen en grupos: filas, columnas, clientes, categorías. Una
**colección** guarda muchos valores en una sola variable. Cada tipo de colección sirve
para un trabajo distinto, y elegir la correcta vuelve el código corto y claro.

<CaseStudy>
	Daniela quiere contar las ventas por categoría y saber cuántos clientes
	distintos compraron algo. Un diccionario hace lo primero y un conjunto lo
	segundo.
</CaseStudy>

## Las cuatro colecciones

| Colección   | Se escribe como  | Idea clave                             | Uso de ejemplo                     |
| ----------- | ---------------- | -------------------------------------- | ---------------------------------- |
| Lista       | `[a, b, c]`      | Ordenada, puede cambiar, puede repetir | Las filas de un archivo            |
| Diccionario | `{"key": value}` | Buscar un valor por su clave           | Conteo por categoría               |
| Tupla       | `(a, b)`         | Ordenada, no puede cambiar             | Un par fijo, como un ID y un monto |
| Conjunto    | `{a, b, c}`      | Sin repetidos, sin orden               | Clientes distintos                 |

## En acción

<Example file="part04/10_collections.py" />

- `rows[:3]` toma los primeros tres elementos de una lista. El conteo empieza en cero:
  `rows[0]` es el primero.
- El diccionario `counts` asigna a cada categoría, tal como está escrita, cuántas veces
  aparece. `counts.get(key, 0)` devuelve cero para una clave que todavía no se ha visto.
- La comprensión de conjunto `{row[2] for row in rows if row[2]}` reúne los clientes,
  ignorando los vacíos y los repetidos. Hay 8 clientes distintos.

El conteo también muestra el desorden en las categorías: `café` aparece 36 veces, pero
`Café` 3 veces y `cafe` 4 veces por separado. El `simplify` de la lección 4.9 las une.

## Errores comunes

- **Empezar a contar desde 1.** Las posiciones empiezan en 0.
- **Cambiar una lista mientras recorres un bucle sobre ella.** Construye una nueva (lección 4.11).
- **Esperar orden de un conjunto.** Los conjuntos no tienen orden.
- **Usar una lista para buscar cosas.** Un diccionario es mucho más rápido y claro.
- **Olvidar que una clave debe existir.** Usa `.get()` con un valor predeterminado.
