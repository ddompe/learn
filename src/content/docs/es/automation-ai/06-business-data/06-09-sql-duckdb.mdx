## Por qué importa

**SQL** (Structured Query Language, lenguaje de consulta estructurado) es el lenguaje
estándar para hacerle preguntas a las tablas. Las bases de datos, los almacenes de datos
y las herramientas de análisis lo hablan. Aprender un poco de SQL te permite comunicarte
con ellos y te da una segunda forma de comprobar tus resultados de pandas. **DuckDB** es
una base de datos pequeña que se ejecuta dentro de tu programa de Python, así que no hay
nada que instalar ni poner en marcha. Consulta directamente DataFrames, archivos CSV y
archivos Parquet.

## La forma de una consulta

Una consulta dice lo que quieres, no cómo calcularlo.

```text
SELECT categoria, count(*) AS ventas, round(sum(monto), 2) AS total
FROM sales
GROUP BY categoria
ORDER BY total DESC
```

| Cláusula   | Significado                            | Equivalente en pandas  |
| ---------- | -------------------------------------- | ---------------------- |
| `SELECT`   | Qué columnas o cálculos                | Elegir columnas, `agg` |
| `FROM`     | Qué tabla                              | El DataFrame           |
| `WHERE`    | Conservar solo las filas que coinciden | Filtro booleano        |
| `GROUP BY` | Una fila por grupo                     | `groupby`              |
| `ORDER BY` | Ordenar el resultado                   | `sort_values`          |

## Cuándo elegir SQL o pandas

Usa pandas para limpiar y reorganizar en Python. Usa SQL cuando los datos estén en una
base de datos, cuando la pregunta sea un resumen simple o cuando tus colegas ya lean SQL.
Muchos analistas combinan ambos.

## Errores comunes

- **Comillas dobles alrededor de valores de texto.** En SQL significan nombres de columna. Usa comillas simples.
- **Olvidar `GROUP BY`** al mezclar una columna y una suma.
- **Consultar datos sin limpiar.** Limpia primero, o los grupos serán incorrectos.
- **Confiar en SQL generado sin ejecutar una comprobación.**
- **Suponer que todas las bases de datos comparten todas las funciones.** Los dialectos difieren un poco.
