## Por qué importa

Casi toda pregunta sobre datos empieza con "solo los...": solo el jugo, solo la primera
semana, solo las ventas sin cliente. En Excel usas filtros. En pandas escribes las
condiciones, y pasan a ser parte de un script que se puede repetir. La sintaxis tiene
algunas trampas que vale la pena conocer.

<CaseStudy>
	Daniela quiere las ventas de jugo, las ventas grandes de café y las ventas sin
	cliente. La última es una pregunta de calidad de datos: alguien olvidó anotar
	el cliente.
</CaseStudy>

## Seleccionar columnas

Una columna: `sales["monto"]` (una Series). Varias columnas: pasa una **lista**, así que
hay doble corchete: `sales[["ID", "monto"]]` (un DataFrame).

## Filtrar filas

Una condición sobre una columna da una columna de True y False, uno por fila. Si la pones
dentro de corchetes, conserva solo las filas True.

<Example file="part06/03_select_filter.py" />

Este script usa la tabla limpia (la lección 6.4 la construye). Cómo leer la salida:

- `sales["categoria"] == "jugo"` conserva las 55 ventas de jugo.
- Para dos condiciones a la vez, usa `&` para Y y `|` para O, y pon **cada condición entre
  paréntesis**: `(a) & (b)`. El `and` de Python no funciona con columnas.
- Comparar fechas funciona con texto de fecha: `sales["fecha"] < "2024-01-08"` da la primera semana.

## Filtros útiles

| Objetivo                    | Código                                    |
| --------------------------- | ----------------------------------------- |
| Uno de varios valores       | `sales["categoria"].isin(["cafe", "te"])` |
| Distinto de                 | `sales["categoria"] != "te"`              |
| No (invertir una condición) | `~(condition)`                            |
| Valores faltantes           | `sales["cliente"].isna()`                 |
| El texto contiene           | `sales["ID"].str.startswith("T0")`        |

Filtrar da una tabla nueva. Para conservarla, asígnala: `juice = sales[...]`.

## Errores comunes

- **Usar `and`/`or`.** Fallan con columnas. Usa `&` y `|`.
- **Olvidar los paréntesis** alrededor de cada condición.
- **Usar `=` en lugar de `==`.**
- **Corchetes simples para varias columnas.** Usa una lista: `[["a", "b"]]`.
- **Cambiar una tabla filtrada y esperar que cambie la original.**

<Checkpoint question="¿Por qué necesitas paréntesis alrededor de cada condición?">
	`&` tiene mayor precedencia que las comparaciones, así que sin paréntesis
	Python combina las partes equivocadas y produce un error.
</Checkpoint>
