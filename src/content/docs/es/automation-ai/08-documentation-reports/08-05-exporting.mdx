## Por qué importa

No todos tus colegas querrán una página web. El dueño puede querer un PDF para imprimir.
El contador puede querer un archivo de Word para añadir comentarios. Una página web es
lo mejor en pantalla y para compartir un enlace. Con Quarto, la misma fuente produce
todos, y cada uno se mantiene coherente con los datos.

<CaseStudy>
	El dueño pide el informe de enero en PDF, y el contador quiere Word para
	añadir notas. Daniela genera ambos a partir del mismo `monthly_report.qmd`.
</CaseStudy>

## Un comando por formato

```text
uv run quarto render monthly_report.qmd --to html
uv run quarto render monthly_report.qmd --to docx
uv run quarto render monthly_report.qmd --to typst
```

Quarto escribe `monthly_report.html`, `monthly_report.docx` y `monthly_report.pdf`. El
formato `--to typst` produce un PDF. El encabezado del informe de la lección 8.3 ya lista
los tres:

```text
format:
  html: ...
  docx: default
  typst: default
```

Sin `--to`, Quarto genera el primer formato de la lista. Con `--to all` genera todos.

## Elegir un formato

| Formato | Mejor para                              | Cuidado con                                          |
| ------- | --------------------------------------- | ---------------------------------------------------- |
| HTML    | Leer en pantalla, compartir un archivo  | El contenido interactivo no está en Word ni en PDF   |
| Word    | Edición y comentarios de otras personas | Diseño básico. Las ediciones se pierden al regenerar |
| PDF     | Imprimir, archivar, diseño fijo         | Necesita un motor de PDF. No es editable             |

## Motores de PDF

Quarto tiene dos formas de crear un PDF:

- `typst`: Quarto incluye el motor Typst, así que no hace falta instalar nada más. Es la
  más sencilla y la que usa el informe.
- `pdf`: usa LaTeX, un sistema de composición tipográfica independiente. Quarto puede
  instalar una versión pequeña con `quarto install tinytex`. El resultado tiene el
  aspecto académico clásico y requiere más configuración.

Última verificación: 2026-10-03. Las opciones de motores de Quarto cambian entre
versiones. Consulta la
[documentación de Quarto sobre la salida en PDF](https://quarto.org/docs/output-formats/pdf-basics.html)
si algo no funciona.

## El resultado generado

Para los tres formatos del mismo informe que viste, esto significa que el título y la
numeración de la figura se conservan, la tabla aparece como una tabla real y las cifras
en línea son las mismas en cada uno. Abre cada archivo y compáralos con los totales de tu
tabla dinámica.

## La regla de oro

**Nunca edites la salida.** Si el contador añade comentarios al archivo de Word, guarda
esos comentarios como un documento aparte. La siguiente generación reemplaza el archivo.
Todas las correcciones van en la fuente `.qmd`.

funciona?

<Checkpoint question="Muestra la respuesta">
	`--to typst`. Quarto incluye el motor Typst, así que produce el PDF sin
	ninguna instalación adicional.
</Checkpoint>

## Errores comunes

- **Elegir `pdf` sin tener LaTeX instalado.** Usa `typst`, o instala TinyTeX.
- **Editar la salida de Word.** Las ediciones se pierden en la siguiente generación.
- **Esperar gráficos interactivos en Word o PDF.** Usa imágenes estáticas para ellos.
- **Enviar HTML con archivos externos.** Usa `embed-resources: true`.
- **No abrir el resultado.** Revisa cada formato al menos una vez.
