## Por qué importa

El sentido de un informe con código es que las cifras del texto, el gráfico y la tabla
salen todos de los datos, en un solo lugar. Nadie teclea una cifra. Cambias los datos,
vuelves a ejecutar y todo el informe se actualiza, y el texto sigue coincidiendo con la
tabla.

</CaseStudy>

### El encabezado

El encabezado define el título y la fecha. `execute: echo: false` oculta el código, de
modo que los lectores ven resultados, y `warning: false` oculta los mensajes de
advertencia. `jupyter: python3` indica qué motor ejecuta el código. La sección `format`
lista tres salidas (lección 8.5).

### Bloques de código

Un bloque empieza con tres acentos graves y `{python}`, y termina con tres acentos
graves. Las líneas que empiezan con `#|` son **opciones del bloque**. Por ejemplo:

| Opción                   | Efecto                                         |
| ------------------------ | ---------------------------------------------- |
| `#\| echo: true`         | Muestra el código de este bloque               |
| `#\| label: fig-weekly`  | Nombra la figura para que el texto la mencione |
| `#\| fig-cap: "..."`     | Título de la figura                            |
| `#\| tags: [parameters]` | Marca el bloque como parámetros (lección 8.4)  |

Todos los bloques comparten la misma memoria, en orden desde arriba, como en un notebook
(lección 4.5). Se ejecutan una vez cuando se genera el documento.

### Cifras dentro de las oraciones

`{python} count` escrito entre acentos graves simples dentro de una oración es **código
en línea**. Quarto lo ejecuta y escribe el resultado en la oración, así que "55 ventas
por un total de 112,614 colones" nunca puede contradecir los datos. El informe da formato
a las cifras con una f-string: `f"{total:,.0f}"` añade separadores de miles.

### Figuras, tablas y referencias cruzadas

El gráfico semanal es un gráfico normal de matplotlib (lección 7.2). Como el bloque tiene
una etiqueta que empieza con `fig-` y un título, Quarto lo numera, y el texto puede
escribir `@fig-weekly` para decir "Figura 1".

La tabla se construye como texto Markdown, como en la lección 5.6, y se muestra con
`Markdown(...)`. Eso funciona igual en HTML, Word y PDF, sin paquetes adicionales.

## Prueba el código sin generar el informe

Generar el informe toma unos segundos, y un error en medio de un bloque puede ser difícil
de ver. Es útil comprobar que el código se ejecuta por sí solo. El proyecto de ejemplo
incluye un pequeño ayudante que ejecuta los bloques de Python del informe como un script
de Python normal, para que las pruebas (lección 3.9) puedan verificar las cifras. Si el
código falla, ves un traceback común (lección 3.10).

## Errores comunes

- **Dejar el código visible en un informe para la gerencia.** Define `echo: false`.
- **Pegar cifras en el texto.** Usa código en línea.
- **Rutas que dependen de dónde generas el informe.** Quarto ejecuta el código desde la
  carpeta del documento, así que las rutas relativas se miden desde ahí.
- **Un bloque que falla a la mitad.** Ejecuta primero el código por separado.
- **Advertencias en la salida.** Corrige la causa, o ocúltalas a propósito.
- **Una caché desactualizada tras instalar un paquete.** Si Quarto sigue indicando que
  falta un paquete que ya instalaste, elimina la carpeta oculta `.quarto` de tu proyecto
  y vuelve a generar el informe.
