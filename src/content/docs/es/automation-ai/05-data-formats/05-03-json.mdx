## Por qué importa

Cuando los datos tienen estructura, como un cliente con varios números de teléfono, una
tabla plana resulta incómoda. **JSON** (JavaScript Object Notation) maneja el
anidamiento y es la forma estándar en que los programas y los servicios web intercambian
datos. Lo encontrarás en las API (lección 1.12), en configuraciones y en todo lo que
devuelve un servicio de IA.

## Las piezas

JSON tiene solo unos pocos bloques de construcción.

| Pieza    | Se escribe como         | Ejemplo                     |
| -------- | ----------------------- | --------------------------- |
| Objeto   | `{ "key": value, ... }` | `{"id": "C001"}`            |
| Arreglo  | `[ value, value ]`      | `["frecuente", "san josé"]` |
| Cadena   | Comillas dobles         | `"Ana López"`               |
| Número   | Dígitos                 | `1500.5`                    |
| Booleano | `true` o `false`        | `true`                      |
| Nulo     | `null`                  | `null`                      |

Los objetos y los arreglos pueden contenerse entre sí, a cualquier profundidad. En
Python, un objeto se convierte en un diccionario, un arreglo en una lista y `null` en
`None` (lecciones 4.8 y 4.10).

<Mermaid

Reglas que hacen tropezar a los principiantes: las claves y las cadenas deben usar
comillas **dobles**, no hay coma final después del último elemento y **no hay
comentarios**.

## Leer el archivo de clientes

<Example file="part05/03_json.py" />

El archivo real empieza con dos líneas que comienzan con `//`. El JSON estricto no
permite comentarios, así que `json.loads` falla. El script quita primero las líneas de
comentario y luego lee 8 clientes. Algunos tienen el nombre o el correo vacío, y el
script lo informa. En el ejemplo escrito, un correo faltante es `null`.

Fíjate en `ensure_ascii=False` en las dos últimas líneas. Sin él, `json.dumps` escribe
`é` como `\u00e9`. Ambos son JSON válido, pero el primero es más fácil de leer.

## Valores faltantes

JSON puede decir "sin valor" de tres maneras, y los archivos las mezclan: `null`, una
cadena vacía `""` o una clave ausente. Maneja todas. Prueba con `if not value` para
vacío y `None`, o usa `.get("email")` para una clave ausente.

## Errores comunes

- **Tratar como JSON válido un archivo con comentarios.** Quítalos primero, o pide un archivo limpio.
- **Comillas simples o comas finales.** Ambas son inválidas.
- **Suponer que todas las claves existen.** Usa `.get()`.
- **Olvidar `ensure_ascii=False`** al escribir acentos para que los lean personas.
- **Confundir `null`, vacío y ausente.**
