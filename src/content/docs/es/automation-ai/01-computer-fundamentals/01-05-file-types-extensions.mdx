## Por qué importa

Confías en que `sales.csv` es un archivo CSV y `report.xlsx` es un archivo de Excel.
Normalmente es cierto. Pero el nombre es solo una etiqueta que cualquiera puede
cambiar. Cuando un archivo no abre, o se abre como un sinsentido, saber qué hay
realmente adentro es el primer paso.

<CaseStudy>
	Un proveedor le envía a Daniela por correo un archivo llamado `invoice.pdf`.
	No se abre. En realidad es un archivo comprimido en zip al que alguien le
	cambió el nombre. Saber cómo mirar adentro le ahorra una tarde.
</CaseStudy>

## Qué es una extensión

La **extensión** es la parte del nombre de un archivo posterior al último punto, como
`.csv` o `.xlsx`. El sistema operativo la usa para adivinar qué programa debe abrir el
archivo. Eso es todo. Cambiar el nombre de `notes.txt` a `notes.xlsx` no lo convierte
en una hoja de cálculo. Solo hace que Excel intente abrir algo que no puede leer.

Windows oculta las extensiones por defecto. Un archivo llamado `sales.csv.xlsx` aparece
entonces como `sales.csv`, y no puedes saber el tipo real. Puedes mostrarlas en el
Explorador de archivos (**Vista**, luego **Mostrar**, luego **Extensiones de nombre de
archivo**) y en Finder (**Finder**, **Ajustes**, **Avanzado**, luego **Mostrar todas las
extensiones de archivo**).

## Archivos de texto y archivos binarios

Todo archivo es una secuencia de bytes. La pregunta es cómo leerlos.

- Un **archivo de texto** contiene caracteres legibles. CSV, JSON y el simple `.txt` son
  archivos de texto. Puedes abrirlos en un editor de texto.
- Un **archivo binario** contiene bytes que no están pensados para leerse como
  caracteres. Las imágenes, los PDF, los archivos zip y los `.xlsx` de Excel son
  binarios. Un editor de texto muestra un sinsentido.

Ten en cuenta que los archivos `.xlsx` y `.docx` son en realidad archivos zip con varios
archivos de texto pequeños. Por eso puedes ver `PK` en uno dañado.

Muchos formatos binarios empiezan con unos pocos bytes fijos llamados **número
mágico**. Le dice a los programas qué es realmente el archivo. Un archivo zip empieza
con las dos letras `PK`. Un archivo de texto como un CSV no tiene número mágico.
Simplemente empieza con su primer carácter.

## Errores comunes

- **Confiar en la extensión.** Es una pista, no una prueba.
- **Cambiar el nombre para convertir.** Cambiar `.csv` por `.xlsx` no convierte nada. Para
  convertir, abre el archivo en un programa y guárdalo en el nuevo formato.
- **Extensiones ocultas.** Actívalas para ver lo que realmente tienes.
- **Abrir un archivo binario en un editor de texto y guardar.** Esto lo destruye.
- **Suponer que CSV es un solo formato.** Los separadores y las codificaciones varían. Ver la Parte 5.
