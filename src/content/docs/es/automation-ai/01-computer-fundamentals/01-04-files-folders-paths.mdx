## Por qué importa

Todo programa que lee un archivo necesita que le digan dónde está. Esa descripción es
una **ruta**. La mayoría de los errores de "archivo no encontrado" vienen de una ruta
ligeramente equivocada. Si sabes leer rutas, puedes corregir esos errores en segundos.

<CaseStudy>
	En la lección 0.3 descomprimiste los datos de Café Central en una carpeta. Un
	script que quiere leer `cafe_central_sales.csv` necesita la ruta de ese
	archivo. Sin ella, hasta un script perfecto falla.
</CaseStudy>

## El sistema de archivos

Tu computadora guarda la información en un **disco**. El principal está dentro de la
computadora (el disco interno). También puedes conectar otros: una memoria USB, un
disco duro externo o una tarjeta de memoria. Un disco por sí solo es solo una fila muy
larga de espacio de almacenamiento. Nada en él dice "esta parte es el informe de
ventas".

El **sistema de archivos** (en inglés, _filesystem_) es el sistema que añade ese orden.
Mantiene una tabla de nombres y registra qué parte del disco pertenece a cada uno.
Permite agrupar cosas en carpetas y recuerda datos como cuándo se cambió un archivo por
última vez. Cada disco tiene uno, y el sistema operativo (lección 1.1) lo lee por ti.
Distintos discos pueden usar distintos tipos de sistema de archivos, y por eso un disco
de un PC con Windows a veces necesita ayuda para funcionar en una Mac. No necesitas
conocer los tipos. Solo necesitas saber que cada disco llega organizado en carpetas y
archivos.

Llevas años usando un sistema de archivos, a través de un programa que lo dibuja por
ti: el **Explorador de archivos** en Windows o el **Finder** en macOS. Cuando haces doble
clic en una carpeta, arrastras un archivo a otra, o conectas una memoria USB y la ves
aparecer en la barra lateral, estás usando el sistema de archivos.

<Mermaid
	diagram={`flowchart LR
  A["Tú: Explorador de archivos o Finder"] --> B["Sistema operativo"]
  B --> C["Sistema de archivos del disco interno"]
  B --> D["Sistema de archivos de una memoria USB"]`}
/>

En Windows, cada disco recibe una letra (`C:` suele ser el interno, y una memoria USB
podría pasar a ser `E:`). En macOS, todos los discos cuelgan de una sola carpeta
superior, y un disco externo aparece dentro de la carpeta `/Volumes`. Ambos sistemas
terminan con la misma idea, que viene a continuación.

## Archivos y carpetas

Un **archivo** guarda información bajo un nombre. Una **carpeta** (también llamada
directorio) guarda archivos y otras carpetas. Las carpetas dentro de carpetas forman un
árbol.

<Mermaid
	diagram={`flowchart TD
  A["Documents"] --> B["cafe-central"]
  A --> C["taxes"]
  B --> D["cafe_central_sales.csv"]
  B --> E["cafe_central_customers.json"]`}
/>

Una **ruta** enumera las carpetas por las que pasas para llegar a un archivo y termina
con su nombre. Para el archivo de ventas de arriba, los pasos son: Documents, luego
cafe-central, luego el archivo.

## Por qué la automatización necesita rutas como texto

Cuando usas el Explorador de archivos o el Finder, señalas y haces clic. Ves el árbol,
abres carpetas con el ratón y reconoces el archivo por su ícono. Un programa no tiene
ratón ni ojos. No puede "abrir la carpeta cafe-central". La única forma de decirle qué
archivo usar es con **texto** que describa el camino hasta el archivo. Ese texto es la
ruta.

Esto importa para la automatización de tres maneras.

- **Un script la necesita escrita.** Leer `cafe_central_sales.csv` en un script
  significa poner su ruta en el código, como un fragmento de texto.
- **Una ruta se puede reutilizar.** El mismo texto sirve todos los meses, sin hacer
  clic. Eso es lo que permite que una tarea se ejecute sin ti.
- **Un programa puede modificar una ruta.** Un script puede construir
  `sales_2026-03.csv` a partir del nombre de un mes, o recorrer todos los archivos de
  una carpeta. Eso no se puede hacer con el ratón.

Así que el hábito que hay que aprender es este: cuando mires una carpeta en el
Explorador o el Finder, aprende también a leerla como una línea de texto.

## Rutas absolutas y relativas

Una **ruta absoluta** parte de lo más alto del disco. Funciona desde cualquier lugar.
Una **ruta relativa** parte de donde estás ahora. Es más corta, pero significa cosas
distintas en lugares distintos.

| Tipo     | Windows                                             | macOS                                             |
| -------- | --------------------------------------------------- | ------------------------------------------------- |
| Absoluta | `C:\Users\Daniela\Documents\cafe-central\sales.csv` | `/Users/daniela/Documents/cafe-central/sales.csv` |
| Relativa | `cafe-central\sales.csv` (desde `Documents`)        | `cafe-central/sales.csv` (desde `Documents`)      |

Fíjate en tres cosas:

- Windows usa una barra invertida `\` entre carpetas y empieza con una letra de unidad
  como `C:`.
- macOS usa una barra inclinada `/` y empieza con una sola `/`, lo más alto del disco.
- El lugar donde estás "parado" se llama **carpeta actual** o carpeta de trabajo. Las
  rutas relativas se miden desde allí.

Dos atajos son útiles. Un solo punto `.` significa "esta carpeta". Dos puntos `..`
significan "la carpeta que está encima de esta".

## Errores comunes

- **Confundir el nombre que se muestra de una carpeta con su ruta.** Finder y el
  Explorador muestran nombres amigables como "Escritorio". La ruta real es más larga.
- **Usar una ruta relativa desde el lugar equivocado.** La misma ruta relativa apunta a
  archivos distintos según la carpeta actual. Ante la duda, usa una ruta absoluta.
- **Espacios y tildes en los nombres.** Están permitidos, pero algunas herramientas
  necesitan comillas alrededor de la ruta. Prefiere nombres simples como `cafe-central`.
- **Copiar una ruta de Windows en un script de Mac.** Los separadores y la letra de
  unidad no funcionarán.
- **Editar a mano el nombre del archivo.** Un solo error de tipeo hace que la ruta sea incorrecta.

## Compruébalo tú mismo

<Checkpoint question="¿Cuál es la diferencia entre una ruta absoluta y una relativa?">
	Una ruta absoluta parte de lo más alto del disco y funciona desde cualquier
	lugar. Una ruta relativa parte de la carpeta actual.
</Checkpoint>

<Checkpoint question="¿Qué significa `..` en una ruta?">
	La carpeta un nivel por encima de la actual.
</Checkpoint>

<Checkpoint question="¿Por qué una ruta de Windows no funciona en una Mac?">
	Windows usa letras de unidad y barras invertidas. macOS no tiene letras de
	unidad y usa barras inclinadas.
</Checkpoint>
