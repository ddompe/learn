## Por qué importa

A veces un colega no quiere un informe. Quiere cambiar un filtro y ver la respuesta.
**Streamlit** convierte un script de Python en una pequeña aplicación web, con filtros y
gráficos, sin desarrollo web. Es un buen paso intermedio entre un informe estático y un
sistema completo de paneles.

<CaseStudy>
	El dueño quiere ver las ventas de una categoría a la vez, sin pedirle a
	Daniela que vuelva a ejecutar nada.
</CaseStudy>

## Una aplicación es un script que se vuelve a ejecutar

Una aplicación de Streamlit es un archivo de Python. Cada vez que el usuario cambia un
widget, Streamlit **ejecuta el script de nuevo desde el principio** y vuelve a dibujar la
página. Ese es todo el modelo.

	diagram={`flowchart LR
  A["El usuario cambia un filtro"] --> B["Streamlit vuelve a ejecutar el script"]

  D --> A`}

## La aplicación

<Example file="part07/05_app.py" />

- `st.title`, `st.metric`, `st.bar_chart` y `st.dataframe` dibujan elementos en la página.
- `st.multiselect` muestra un widget y devuelve lo que eligió el usuario. El script filtra
  los datos con él, exactamente como en la lección 6.3.
- Los datos provienen de la misma función de limpieza de antes. La aplicación reutiliza tu trabajo.

## Ejecútala

Desde la carpeta del proyecto:

```text
uv run streamlit run part07/05_app.py
```

Tu navegador se abre en una dirección como `http://localhost:8501`. Cambia el filtro de
categoría y los números y el gráfico cambian. Detén la aplicación con **Ctrl+C** en la
terminal.

Como la aplicación tiene una prueba (Streamlit puede ejecutar una aplicación sin interfaz
y comprobar lo que muestra), puedes estar seguro de que sigue funcionando después de
cambiarla.

## Compartir una aplicación

Opciones, de la más segura a la más abierta:

1. **Ejecútala tú mismo** y muéstrala en tu pantalla.
2. **Ejecútala en tu computadora para colegas de la misma red.** La dirección aparece en la terminal. Hazlo solo si la política de la empresa lo permite.
3. **Alójala** en un servicio o en un servidor de la empresa. Los servicios de alojamiento y sus niveles gratuitos cambian.
   Consulta la documentación oficial de Streamlit. Verificado por última vez el 2026-10-03.

Antes de compartir, pregunta: ¿qué datos contiene la aplicación y quién los verá? Una
aplicación es una ventana a tus datos. No publiques información de clientes (lección 2.8).
Nunca pongas claves en el código de la aplicación (lección 3.7).

## Errores comunes

- **Leer los datos dentro de cada nueva ejecución** cuando es lento. Streamlit tiene caché; pregúntale a tu asistente sobre ella cuando la aplicación se sienta lenta.
- **Compartir una aplicación con datos privados.**
- **Poner secretos en el código.**
- **Olvidar que el script se vuelve a ejecutar desde el principio,** así que las variables no persisten por sí solas.
- **Construir primero una aplicación grande.** Empieza con un filtro y un gráfico.

## Compruébalo tú mismo

</Checkpoint>

<Checkpoint question="¿Qué comando inicia la aplicación?">
	`uv run streamlit run` seguido de la ruta del archivo.
