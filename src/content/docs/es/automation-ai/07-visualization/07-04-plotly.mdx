## Por qué importa

Una imagen estática responde una pregunta. Un gráfico **interactivo** permite al lector
pasar el cursor para ver valores exactos, ampliar un período y hacer clic en las entradas
de la leyenda para ocultar líneas. Eso ayuda cuando un gráfico tiene muchas líneas o
muchos detalles y el lector quiere explorar.

<CaseStudy>
	El dueño quiere comparar categorías semana a semana y consultar el valor
	exacto de un punto.
</CaseStudy>

## Un gráfico como página web

**Plotly** dibuja gráficos en un navegador con JavaScript. Desde Python, describes el
gráfico y Plotly escribe un archivo HTML que se abre en cualquier navegador.

<Example file="part07/04_plotly.py" />

`plotly.express` (importado como `px`) crea un gráfico a partir de una tabla ordenada en
una sola llamada: `x`, `y` y `color` eligen las columnas, y `markers=True` marca cada
semana.

Pruébalo tú mismo a continuación. Pasa el cursor sobre un punto, haz doble clic para
restablecer el zoom y haz clic en un nombre de la leyenda para ocultar esa línea.

## Cosas que debes saber

- La página carga la biblioteca de Plotly desde internet (`include_plotlyjs="cdn"`), lo que mantiene
  el archivo pequeño. Necesita conexión. Para un archivo sin conexión, usa `include_plotlyjs=True` y espera un archivo de varios megabytes.
- El archivo es un programa que se ejecuta en el navegador del lector. Comparte solo gráficos construidos con datos
  que tengas permitido compartir (lección 2.8). Los datos están dentro del archivo.
- Los gráficos interactivos son más difíciles de poner en un informe impreso o en un archivo de Word. Para esos casos, usa una imagen estática (lección 7.2).

## Errores comunes

- **Compartir un archivo interactivo que contiene datos privados.**
- **Olvidar que la versión con CDN necesita internet.**
- **Usarlo para material impreso.**
- **Demasiadas líneas.** La interacción ayuda, pero diez líneas siguen siendo difíciles de leer.
- **Depender del cursor para el mensaje clave.** Ponlo en el título.

## Compruébalo tú mismo

<Checkpoint question="¿Qué ofrece un gráfico interactivo?">
	Pasar el cursor para ver valores exactos, ampliar, y ocultar o mostrar líneas.
</Checkpoint>

<Checkpoint question="¿Por qué un lector sin conexión no puede ver un gráfico basado en CDN?">
	La página carga la biblioteca de Plotly desde internet al abrirse.
</Checkpoint>

<Checkpoint question="¿Cuándo es mejor una imagen estática?">
	Para documentos impresos, archivos de Word y en cualquier lugar donde la
	interacción sea imposible.
</Checkpoint>
