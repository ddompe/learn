La Parte 0 es la orientación. Descubres si este curso es para ti, qué ruta de aprendizaje seguir, qué es y qué no es la automatización, y quién es Café Central. También ves cómo está organizada cada lección, para que el resto del curso te resulte familiar.

Aquí no hay instalación ni código. Las cuatro lecciones toman alrededor de una hora, y puedes leer rápido la 0.4 si tienes poco tiempo.
