## Why this matters

**matplotlib** is the foundation of charting in Python. Other libraries, such as seaborn,
are built on it. With it, you can produce exactly the chart that a report needs and save
it as a file that can go into a document (Part 8) or an email.

<CaseStudy>
	Daniela needs a clear chart of January sales by category for the owner's
	monthly report.
</CaseStudy>

## Figure and axes

In matplotlib, a **figure** is the whole picture and an **axes** (singular: axis) is one chart inside it.
You make both with one call, `plt.subplots()`, and then draw on the axes.

## A first chart

<Example file="part07/02_matplotlib.py" />

![Horizontal bar chart of January 2024 sales by category, sorted from te at the bottom to sandwich at the top, each bar labelled with its total in colones.](/charts/automation-ai/part07/02_category_totals.png)

What each part does:

- The totals come from the cleaned table of lesson 6.4, as a `groupby` sum. They are sorted so the bars appear in order.
- `barh` draws horizontal bars. Long category names fit better.
- `bar_label` writes each value at the end of its bar, so readers don't need to estimate.
- The title, the axis label with the unit (colones), and a little extra room on the right for the labels.
- The top and right frame lines are hidden, as they add nothing.
- `savefig` writes a PNG file. The script uses a mode that draws straight to files, so it works on a server with no screen.

The amounts are converted to ordinary decimals (floats) for drawing only. The exact `Decimal` values stay in the table, and the chart is a picture, not a calculation.

## Habits

1. **Title** says what the chart shows. **Axis labels** include the unit.
2. **Save to a file** with a clear name, rather than relying on a window.
3. **Close the figure** with `plt.close()` after saving, so memory is released when you make many charts.
4. **Keep the chart code in a function** so it can be reused each month (Part 9).

## Common mistakes

- **Forgetting the unit** on the axis.
- **Using `plt.show()` in a script that should save a file.**
- **Plotting `Decimal` values directly.** Convert to float for drawing.
- **Many charts, no `close`.** Memory grows.
- **Default blue-orange palettes with no meaning.** Use one colour unless colour carries information.
