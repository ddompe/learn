## Why this matters

A static image answers one question. An **interactive** chart lets the reader hover to see
exact values, zoom into a period, and click legend entries to hide lines. That helps when a
chart has many lines or many details, and the reader wants to explore.

<CaseStudy>
	The owner wants to compare categories week by week, and look up the exact
	value of a point.
</CaseStudy>

## A chart as a web page

**Plotly** draws charts in a browser with JavaScript. From Python, you describe the chart,
and Plotly writes an HTML file that opens in any browser.

<Example file="part07/04_plotly.py" />

`plotly.express` (imported as `px`) makes a chart from a tidy table in one call: `x`, `y`,
and `color` pick the columns, and `markers=True` marks each week.

Try it yourself below. Hover over a point, double-click to reset the zoom, and click a name in the
legend to hide that line.

## Things to know

- The page loads the Plotly library from the internet (`include_plotlyjs="cdn"`), which keeps
  the file small. It needs a connection. For an offline file, use `include_plotlyjs=True`, and expect a file of several megabytes.
- The file is a program that runs in the reader's browser. Only share charts built from data
  you are allowed to share (lesson 2.8). The data is inside the file.
- Interactive charts are harder to put in a printed report or a Word file. For those, use a static image (lesson 7.2).

## Common mistakes

- **Sharing an interactive file that holds private data.**
- **Forgetting that the CDN version needs internet.**
- **Using it for printed output.**
- **Too many lines.** Interaction helps, but ten lines are still hard to read.
- **Relying on hover for the key message.** Put it in the title.

## Check yourself

<Checkpoint question="What does an interactive chart offer?">
	Hovering for exact values, zooming, and hiding or showing lines.
</Checkpoint>

<Checkpoint question="Why can an offline reader not see a CDN-based chart?">
	The page loads the Plotly library from the internet when it opens.
</Checkpoint>

<Checkpoint question="When is a static image better?">
	For printed documents, Word files, and anywhere interaction is impossible.
</Checkpoint>
