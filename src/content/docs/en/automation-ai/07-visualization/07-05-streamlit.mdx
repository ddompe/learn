## Why this matters

Sometimes a colleague does not want a report. They want to change a filter and see the answer.
**Streamlit** turns a Python script into a small web app, with filters and charts, with no
web development. It is a good step between a static report and a full dashboard system.

<CaseStudy>
	The owner wants to look at sales for one category at a time, without asking
	Daniela to rerun anything.
</CaseStudy>

## An app is a script that reruns

A Streamlit app is a Python file. Each time the user changes a widget, Streamlit **runs the
script again from the top** and redraws the page. That is the whole model.

## The app

<Example file="part07/05_app.py" />

- `st.title`, `st.metric`, `st.bar_chart`, and `st.dataframe` draw things on the page.
- `st.multiselect` shows a widget and returns what the user picked. The script filters
  the data with it, exactly as in lesson 6.3.
- The data comes from the same cleaning function as before. The app reuses your work.

## Run it

From the project folder:

```text
uv run streamlit run part07/05_app.py
```

Your browser opens at an address like `http://localhost:8501`. Change the category filter,
and the numbers and chart change. Stop the app with **Ctrl+C** in the terminal.

Because the app has a test (Streamlit can run an app headlessly and check what it shows),
you can be sure that it still works after you change it.

## Sharing an app

Options, from safest to most open:

1. **Run it yourself** and show it on your screen.
2. **Run it on your computer for colleagues on the same network.** The address is shown in the terminal. Only do this if company policy permits it.
3. **Host it** on a service or a company server. Hosting services and their free tiers change.
   Check the official Streamlit documentation. Last verified on 2026-10-03.

Before sharing, ask: what data does the app contain, and who will see it? An app is a window
into your data. Do not publish customer information (lesson 2.8). Never put keys in the app's
code (lesson 3.7).

## Common mistakes

- **Reading the data inside the loop of every rerun** when it is slow. Streamlit has caching; ask your assistant about it once the app feels slow.
- **Sharing an app with private data.**
- **Putting secrets in the code.**
- **Forgetting that the script reruns from the top,** so variables do not persist by themselves.
- **Building a big app first.** Start with one filter and one chart.
