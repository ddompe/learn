Part 1 explains the basics that every later part relies on. Work through the twelve
lessons in order. No installation is needed, and you do not have to run any code.

## Lessons

| Lesson                                                                                                                  | What it covers                                                                                        | Minutes |
| ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------- |
| [1.1 Hardware, operating systems, and applications](/en/automation-ai/01-computer-fundamentals/01-01-hardware-os-apps/) | Learn the three layers every computer is built from and what each one is responsible for.             | 15      |
| [1.2 Windows, macOS, and Linux](/en/automation-ai/01-computer-fundamentals/01-02-windows-macos-linux/)                  | Know the differences between operating systems that cause real problems when sharing files and code.  | 15      |
| [1.3 Bits, bytes, and units](/en/automation-ai/01-computer-fundamentals/01-03-bits-bytes-units/)                        | Understand how computers measure data, and why a 1 TB disk shows up as 931 GB.                        | 15      |
| [1.4 Files, folders, and paths](/en/automation-ai/01-computer-fundamentals/01-04-files-folders-paths/)                  | Describe where a file lives using absolute and relative paths on Windows and macOS.                   | 20      |
| [1.5 File types and extensions](/en/automation-ai/01-computer-fundamentals/01-05-file-types-extensions/)                | Learn that an extension is a label, not a guarantee, and how to tell what a file really contains.     | 15      |
| [1.6 Cloud-synced folders](/en/automation-ai/01-computer-fundamentals/01-06-cloud-synced-folders/)                      | Understand how OneDrive and similar tools differ from local folders, and why they can break projects. | 15      |
| [1.7 Text and encodings](/en/automation-ai/01-computer-fundamentals/01-07-text-encodings/)                              | Understand how text becomes bytes, and diagnose accents that turn into strange symbols.               | 20      |
| [1.8 Numbers inside computers](/en/automation-ai/01-computer-fundamentals/01-08-numbers-inside-computers/)              | Learn why integers and decimals behave differently, and why money needs exact decimals.               | 15      |
| [1.9 The terminal](/en/automation-ai/01-computer-fundamentals/01-09-terminal/)                                          | Open a terminal, move between folders, list files, and read what the computer answers.                | 25      |
| [1.10 PATH and environment variables](/en/automation-ai/01-computer-fundamentals/01-10-path-environment-variables/)     | Understand how the shell finds programs, and how to read and set an environment variable.             | 20      |
| [1.11 Networks and the web in 15 minutes](/en/automation-ai/01-computer-fundamentals/01-11-networks-web/)               | Understand clients, servers, URLs, and the request and response behind every web page.                | 15      |
| [1.12 APIs and API keys](/en/automation-ai/01-computer-fundamentals/01-12-apis-api-keys/)                               | Understand what an API is and why an API key must be treated like a password.                         | 15      |
