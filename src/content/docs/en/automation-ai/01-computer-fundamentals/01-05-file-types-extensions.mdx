## Why this matters

You trust that `sales.csv` is a CSV file and `report.xlsx` is an Excel file. Usually,
that is true. But the name is just a label that anyone can change. When a file will not
open, or opens as nonsense, knowing what is really inside is the first step.

<CaseStudy>
	A supplier emails Daniela a file called `invoice.pdf`. It will not open. The
	file is actually a zipped archive someone renamed. Knowing how to look inside
	saves her an afternoon.
</CaseStudy>

## What an extension is

The **extension** is the part of a file name after the last dot, such as `.csv` or `.xlsx`.
The operating system uses it to guess which program should open the file. That is all.
Renaming `notes.txt` to `notes.xlsx` does not turn it into a spreadsheet. It only
makes Excel try to open something it cannot read.

Windows hides extensions by default. A file called `sales.csv.xlsx` then appears as
`sales.csv`, and you cannot tell the real type. You can show them in File Explorer
(**View**, then **Show**, then **File name extensions**) and in Finder (**Finder**,
**Settings**, **Advanced**, then **Show all filename extensions**).

## Text files and binary files

Every file is a sequence of bytes. The question is how to read them.

- A **text file** holds readable characters. CSV, JSON, and plain `.txt` are text
  files. You can open them in a text editor.
- A **binary file** holds bytes that are not meant to be read as characters. Images,
  PDFs, zip archives, and Excel `.xlsx` files are binary. A text editor shows nonsense.

Note that `.xlsx` and `.docx` files are actually zip archives of several small text files.
That is why you may see `PK` in a damaged one.

Many binary formats start with a few fixed bytes called a **magic number**. It tells
programs what the file really is. A zip archive starts with the two letters `PK`.
A text file such as CSV has no magic number. It just begins with its first character.

## Common mistakes

- **Trusting the extension.** It is a hint, not proof.
- **Renaming to convert.** Changing `.csv` to `.xlsx` does not convert anything. To convert,
  open the file in a program and save it in the new format.
- **Hidden extensions.** Turn them on, so you see what you really have.
- **Opening a binary file in a text editor and saving.** This destroys it.
- **Assuming CSV is one format.** Separators and encodings vary. See Part 5.
