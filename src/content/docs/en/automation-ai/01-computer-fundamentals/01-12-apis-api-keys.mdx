## Why this matters

Many services you will use, including AI tools, offer a way for programs to talk to them
directly. You need to understand the concept of an API, because one costly mistake is
easy to make: sharing a key that anyone can use to spend your money.

This lesson is concept only. You will not create or use a key here.

<CaseStudy>
	Café Central uses a service that sends the shops' daily weather. A script asks
	the service for the forecast. The service needs to know who is asking, so that
	it can limit use and bill the right company. That identity is the API key.
</CaseStudy>

## What an API is

An **API** (application programming interface) is a doorway that lets one program
talk to another. A web page is made for people. An API is made for programs: it answers
with data, not a styled page.

Think of a restaurant. You do not walk into the kitchen. You read the menu, order
through the waiter, and get a dish. The menu is the API. The waiter takes your request
to the kitchen and brings the answer back. Unlike a restaurant, the "waiter" is a web
request, as you saw in lesson 1.11.

## What an API key is

An **API key** is a long string of letters and digits that identifies who is calling.
The service uses it to:

- Know which account to charge.
- Limit how much each customer can use.
- Block abuse.

## Why a key is a secret

Anyone who has your key can act as you. They can run up costs on your account or read
data that belongs to you. Keys often leak by accident:

- Pasted into a chat, an email, or an AI assistant.
- Saved in a file that is shared or uploaded to a public site.
- Included in a screenshot.

Good habits:

1. Treat a key like a password. Never share it.
2. Do not put it in files you share or upload. Part 3 teaches how to keep it out.
3. Use a separate key for each purpose, so that you can cancel one without breaking the rest.
4. If a key leaks, **revoke it** at once on the service's website and create a new one.

## Hands-on

### Worked example

Read this fictional request. The key is made up.

```text
GET /forecast?city=San+Jose
Host: weather.example.com
Authorization: Bearer cafe-demo-1234567890
```

The first line asks for a forecast for San José. The `Authorization` line carries the
key. If this request were sent in an email, the key would travel with it.

## Common mistakes

- **Pasting a key into a chat.** Remove it before you paste anything.
- **Committing a key to a shared project.** Part 3 explains how to avoid this.
- **Taking a screenshot with the key visible.**
- **Sharing a single key between many people.** Create one key for each person or purpose.
- **Ignoring a leak.** Revoke the key immediately, even if you think no one noticed.
