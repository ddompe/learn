## What they never taught you

Business professionals who are fluent in Excel and PowerBI can get a lot further with
AI assistants than they currently do — the missing piece isn't the AI, it's the
computing fundamentals nobody taught them. This course closes that gap: files and
paths, the terminal, version control, Python, and how to prompt an AI assistant well,
all taught through one running case study, Café Central.

## Who this is for

Analysts, finance and operations staff, project managers, and anyone fluent in Office
tools who wants to automate repetitive work. No programming background assumed.

## Learning paths

| Path                      | What it covers                                                                                                                   |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| AI-literate professional  | A short path through computer fundamentals and how LLMs actually work — enough to use AI tools well without writing code.        |
| Business automator (core) | The full path: computer fundamentals, Python, business data, visualization, and reporting, ending in a real automation capstone. |
| Advanced                  | Calling LLMs from Python code — for learners who complete the core path.                                                         |
