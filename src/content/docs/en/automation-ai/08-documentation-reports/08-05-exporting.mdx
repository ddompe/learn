## Why this matters

Your colleagues will not all want a web page. The owner may want a PDF to print. The
accountant may want a Word file to add comments. A web page is best on a screen and for
sharing a link. With Quarto, the same source makes all of them, and each one stays
consistent with the data.

<CaseStudy>
	The owner asks for the January report as a PDF, and the accountant wants Word
	to add notes. Daniela renders both from the one `monthly_report.qmd`.
</CaseStudy>

## One command per format

```text
uv run quarto render monthly_report.qmd --to html
uv run quarto render monthly_report.qmd --to docx
uv run quarto render monthly_report.qmd --to typst
```

Quarto writes `monthly_report.html`, `monthly_report.docx`, and `monthly_report.pdf`. The
`--to typst` format produces a PDF. The header of the report from lesson 8.3 already lists the three:

```text
format:
  html: ...
  docx: default
  typst: default
```

Without `--to`, Quarto renders the first format in the list. With `--to all` it renders every one.

## Choosing a format

| Format | Best for                          | Watch out for                                |
| ------ | --------------------------------- | -------------------------------------------- |
| HTML   | Reading on screen, sharing a file | Interactive content is not in Word or PDF    |
| Word   | Editing and comments by others    | Layout is basic. Edits are lost on re-render |
| PDF    | Printing, archiving, fixed layout | Needs a PDF engine. Not editable             |

## PDF engines

Quarto has two ways to make a PDF:

- `typst`: Quarto includes the Typst engine, so no extra installation is needed. This is the simplest. It is what the report uses.
- `pdf`: uses LaTeX, a separate typesetting system. Quarto can install a small version
  with `quarto install tinytex`. The result is the classic academic look, and it takes more setup.

Last verified on 2026-10-03. Quarto's choices of engines change between versions. Check the
[Quarto documentation on PDF output](https://quarto.org/docs/output-formats/pdf-basics.html)
if something does not work.

## Rendering the result

For all three formats of the same report you saw, this means: the figure caption and
numbering carry over, the table appears as a real table, and the inline numbers are the same
in each. Open each file and compare them with the totals from your pivot.

## The golden rule

**Never edit the output.** If the accountant adds comments to the Word file, keep those
comments as a separate document. The next render replaces the file. All fixes go into the
`.qmd` source.

## Common mistakes

- **Choosing `pdf` without LaTeX installed.** Use `typst`, or install TinyTeX.
- **Editing the Word output.** Edits are lost at the next render.
- **Expecting interactive charts in Word or PDF.** Use static images for those.
- **Sending HTML with external files.** Use `embed-resources: true`.
- **Not opening the result.** Check each format once.
