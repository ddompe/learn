## Why this matters

A report that is pasted together by hand is out of date the day after you make it. **Quarto**
is a tool that builds documents from text and code: you write the report once, and Quarto
runs the code, inserts the results, and produces HTML, Word, or PDF. Next month you
rerun it. This is how a monthly report becomes an automation.

<CaseStudy>
	Each month Daniela copies numbers into a Word file and pastes a chart. With
	Quarto, the numbers and the chart are produced by the report itself.
</CaseStudy>

## How Quarto works

A Quarto document is a text file ending in `.qmd`. It has three kinds of content:

1. A **header** between `---` lines, with settings such as the title and output formats (YAML,
   lesson 5.4).
2. **Text** written in Markdown (lesson 5.6).
3. **Code chunks** in Python (lesson 8.3), which Quarto runs.

## Install it

Quarto is a separate program from Python. Download it from the official site,
[quarto.org](https://quarto.org/docs/get-started/). Its documentation lists the current installers.
Last verified on 2026-10-03.

- On a personal computer, the normal installer for your system works.
- On a managed laptop, an installer may need administrator rights. If so, ask IT, or use
  the download that is a compressed archive (`.tar.gz` on macOS and Linux, `.zip` on Windows). Unpack it into a
  folder in your user directory, and add that folder's `bin` subfolder to your PATH (lesson 1.10).
  Do this only if company policy allows it.

Then check, in a new terminal:

```text
quarto --version
quarto check
```

`quarto check` tests the installation, including whether it finds your project's Python.
Quarto runs your code with the Python it finds first. Starting it through `uv run` makes it use the
project's environment, so use it for every command:

```text
uv add ipykernel nbformat nbclient
uv run quarto check
```

In VS Code, install the **Quarto** extension for syntax colours and a preview button.

## A first document

<Example file="part08/hello.qmd" />

Render it:

```text
uv run quarto render hello.qmd
```

Quarto writes `hello.html` next to the source. The setting `embed-resources: true` packs the page, its styles, and its images into that one file, so you can email it. Without it, Quarto also writes a folder of support files that must travel with the page. Open it in a
browser. For a live preview that refreshes as you save, use `uv run quarto preview hello.qmd`.

Everything you see in the page comes from the file: the heading, the list, the link, and the
table. There is no code yet. That comes next.

## Common mistakes

- **Running `quarto` outside `uv run`.** It may use a different Python, without your packages.
- **Installing Quarto in a folder not on PATH.**
- **Editing the HTML.** It is rebuilt on the next render. Edit the `.qmd`.
- **Committing the rendered output** by accident, if it is large. Ignore it in `.gitignore`, unless you want it in the repository.
- **Forgetting the quotes in YAML values with colons.** The title `"Café: report"` needs them.
