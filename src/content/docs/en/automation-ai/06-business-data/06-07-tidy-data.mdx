## Why this matters

People build spreadsheets to be **read**: months across the top, shops down the side,
totals at the bottom. Programs need data to be **processed**: one row per observation, one
column per variable. A table that is easy to read is often hard to group, filter, or chart.
Knowing the difference saves a lot of rework.

<CaseStudy>
	The monthly summary workbook has a column for each month and measure. Next
	month, someone adds new columns. Daniela's formulas break. As tidy rows, the
	next month would just be new rows.
</CaseStudy>

## What tidy means

Data is **tidy** when:

1. Each **variable** is a column.
2. Each **observation** is a row.
3. Each kind of observation is in its own table.

In the summary workbook, "month" is not a column. It is hidden in the headers `Diciembre 2023`
and `Enero 2024`, and so are the measures `Ventas` and `Monto`. The shop is a column, but the
numbers for several months and measures live side by side.

| Wide (for reading)          | Tidy (for processing)                |
| --------------------------- | ------------------------------------ |
| One row per shop            | One row per shop, month, and measure |
| New month means new columns | New month means new rows             |
| Hard to group by month      | `groupby("mes")`                     |

## Reshaping

Reshaping from wide to long is called **unpivoting**, and pandas offers `melt` for it. The
example below does it with an explicit loop, so each step is visible.

<Example file="part06/07_tidy.py" />

The 3 shops, 2 months, and 2 measures give 12 rows, each saying one thing: this shop, in this month, had this value for this measure. Now grouping by month is one line, and a new month needs no new code.

Notice that we dropped the `Total` row. Totals are a calculation from the data, and do not belong in it. You can always recompute them.

## Common mistakes

- **Treating the "pretty" report as the dataset.**
- **Keeping totals inside the data.**
- **Putting values in column names.**
- **Reshaping before cleaning.** Clean first.
- **Losing labels when unpivoting.** Keep the shop and the month in each row.
