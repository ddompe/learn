## Why this matters

The last step of most business analysis is handing someone a file. They will open it in
Excel, not in Python. A file with raw column names, a stray index, and a narrow column
that shows `####` makes your work look careless, and invites mistakes. A few lines of
formatting fix that.

<CaseStudy>
	Daniela sends the category totals to the owner each month. She wants a clean
	sheet with a bold header, thousands separators, and a frozen top row.
</CaseStudy>

## Write, then format

1. `DataFrame.to_excel(path, index=False)` writes the table. `index=False` stops the
   row numbers from appearing as a column.
2. **openpyxl** then opens the file to style it (lesson 6.1).

<Example file="part06/10_excel_output.py" />

What it does:

- Bold white text on a coloured fill for the header.
- `number_format = "#,##0.00"` shows thousands separators and two decimals. The cell still
  holds a number, so it can be summed. Only the look changes.
- Column widths are set from the longest value in each column.
- `freeze_panes = "A2"` keeps the header visible when scrolling.
- The script **reads the file back** and prints what it finds. Never assume a file is right because the code ran.

## Rules for sharing files

1. **Numbers as numbers.** Don't write text such as "1,500.00".
2. **Dates as dates,** with a date format.
3. **One header row,** no merged cells. The people downstream may want to use the data.
4. **Write a new file.** Don't overwrite someone's workbook.
5. **Put notes on a separate sheet,** not in the data area.
6. **Open it in Excel before sending it.** Look at it once.

### Your turn

The `total` column shows `81111.5` and the owner wants `81,111.50`. Which setting changes that, and does it change the stored number?

<Checkpoint question="Show the answer">
	The number format of the cells: `#,##0.00`. It changes only how the number
	looks. The value stays 81111.5, so formulas and sums still work.
</Checkpoint>

## Common mistakes

- **Leaving the index column in.**
- **Writing numbers as formatted text.**
- **Merging cells for looks.**
- **Not checking the file in Excel.**
- **Overwriting the source workbook.**

## Check yourself

<Checkpoint question="Why use index=False?">
	It stops pandas from writing the row numbers as an extra column.
</Checkpoint>

<Checkpoint question="Does a number format change the value in the cell?">
	No. It changes only how the value is displayed.
</Checkpoint>

<Checkpoint question="Why read the file back after writing it?">
	To confirm that the file has what you intended, instead of assuming.
</Checkpoint>
