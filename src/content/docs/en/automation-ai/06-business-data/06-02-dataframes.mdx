## Why this matters

pandas is the main tool for tabular data in Python, and the **DataFrame** is its
central object. If you think of it as an Excel sheet that you control with code, you are
partly right. The parts where you are wrong will cost you hours, so this lesson covers both.

<CaseStudy>
	Daniela loads the sales CSV into a DataFrame and wants to know: how big is it,
	what are the columns, and what type is each one?
</CaseStudy>

## The analogy

| Excel                              | pandas                                         |
| ---------------------------------- | ---------------------------------------------- |
| A sheet                            | A DataFrame                                    |
| A column header                    | A column name                                  |
| A column of cells                  | A **Series** (a column with a name and a type) |
| A row number                       | The **index** (labels for rows)                |
| A cell format (number, text, date) | A **dtype** (data type of the column)          |
| A formula in a cell                | An operation on a whole column                 |

## Where the analogy breaks

1. **Every column has one type.** In Excel, a column can hold numbers and text mixed. In pandas,
   a column that mixes them becomes text (or "object").
2. **You work on whole columns,** not on cells one by one. `sales["Monto"] * 2` doubles every row at once.
3. **No hidden state.** There are no colours, merged cells, or formulas that carry meaning.
   What you see in the table is all there is.
4. **Operations return new tables.** Your original is not changed unless you assign the result.

## First look

<Example file="part06/02_dataframe.py" />

- `shape` is `(246, 5)`: 246 rows and 5 columns.
- `dtypes` lists the type of each column. Here, all are `str` (text), including `Monto`
  and `Fecha`. A CSV has no types, and the messy formats stop pandas from guessing numbers or dates.
  That is why lesson 6.4 converts them.
- `head(3)` shows the first three rows. The numbers on the left are the index.
- `sales["Monto"]` selects a column. `sales.iloc[0]` selects the first row by position.

This course uses pandas 3, where text columns have the dtype `str`. In older versions
you will see `object`, which means the same here.

## Common mistakes

- **Expecting numbers from a CSV.** Check `dtypes`.
- **Looping over rows to do arithmetic.** Work on whole columns.
- **Confusing index with position.** `iloc` is by position; `loc` is by label.
- **Modifying a copy.** Assign the result to a name.
- **Printing a huge table.** Use `head()`.
