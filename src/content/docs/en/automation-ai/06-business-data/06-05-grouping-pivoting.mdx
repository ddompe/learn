## Why this matters

The pivot table is the most used analysis tool in Excel. Its logic is: split the rows into
groups, calculate something for each group, and combine the results. pandas does the same,
in code that can be rerun on next month's file, without anyone dragging fields around.

<CaseStudy>
	The owner asks: how much did we sell in each category, and how did each
	category do week by week?
</CaseStudy>

## Split, apply, combine

<Mermaid
	diagram={`flowchart LR
  A["240 rows"] --> B["Split by categoria"]
  B --> C["Apply: count and sum in each group"]
  C --> D["Combine: one row per category"]`}
/>

`groupby("categoria")` splits the table. You then pick a column and what to calculate:

```text
sales.groupby("categoria")["monto"].agg(["count", "sum"])
```

## In action

<Example file="part06/05_group_pivot.py" />

The first table gives, for each category, the number of sales and their total. The grand
total is 474,061.00 colones. This is your **control figure**: you can compare it with
the sum of the cleaned amounts, and with the original file.

The second table is a **pivot table**: categories as rows, ISO week numbers as columns,
and the sum of amounts in the cells. `pivot_table` takes `index` (rows), `columns`,
`values`, and `aggfunc`. It is the same four boxes as the Excel dialog.

The last line is a check: the sum of the whole pivot equals the grand total. If it didn't, a
row would have been lost, for example by a missing value in a grouping column.

## Excel pivot to pandas

| Excel PivotTable box | pandas argument          |
| -------------------- | ------------------------ |
| Rows                 | `index=`                 |
| Columns              | `columns=`               |
| Values               | `values=` and `aggfunc=` |
| Filters              | Filter the table first   |

## Common mistakes

- **Not checking the total.** A pivot that doesn't tie hides lost rows.
- **Grouping by a column with inconsistent text.** `cafe` and `Café` become two groups. Clean first.
- **Missing values in grouping columns.** The default drops those rows from the groups.
- **Averaging averages.** Combine sums and counts instead.
- **Reading the week number as a date.** It is a label.
