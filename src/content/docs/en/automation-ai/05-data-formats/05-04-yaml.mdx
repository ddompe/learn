## Why this matters

**YAML** is a text format designed to be easy for people to write. Many tools use it for
settings: reporting tools, automation systems, and software projects. Where JSON
needs braces and quotes everywhere, YAML uses indentation and plain words. That makes it
pleasant to read, and easy to get subtly wrong.

<CaseStudy>
	Daniela wants the monthly report to read its settings from a file: which
	month, which shops, and how many top categories. A YAML file lets her change
	them without touching the program.
</CaseStudy>

## The shape of YAML

<Example file="part05/04_report_settings.yaml" />

- `key: value` pairs. A key followed by indented lines holds nested values.
- A line starting with a dash and a space is an item of a list.
- `#` starts a comment, which JSON does not allow.
- Indentation uses **spaces**, never tabs. Two spaces per level is the common habit.

YAML is a superset of JSON in practice, but you will mostly write the readable style.

## Reading it in Python

<Example file="part05/04_yaml.py" />

The settings load into dictionaries and lists. Notice `Month: 2024-01 str`: the value is
quoted in the file, so it stays text. Without the quotes, some YAML readers would
guess a type. That guessing is the source of the traps.

## The traps

1. **Indentation is structure.** A line indented one space too few belongs to a different
   parent, or breaks the file. A **tab** is an error.
2. **Words become other types.** In common YAML readers, unquoted `yes`, `no`, `on`, and
   `off` become booleans. A country code `no` (Norway) becomes `False`. Quote strings that might be mistaken.
3. **Numbers lose digits.** `1.10` becomes `1.1`. A version should be quoted: `"1.10"`.
4. **A colon inside a value** can confuse the reader. Quote it.

The `safe_load` function is the safe way to read YAML in Python. Never use plain `load` on
files you did not write, because it can run code.

## Common mistakes

- **Using tabs for indentation.**
- **Forgetting to quote values that look like other types.** Dates, versions, `yes`, `no`.
- **Mixing indentation widths.**
- **Using `yaml.load` on untrusted input.** Use `safe_load`.
- **Editing in a tool that changes indentation.**
