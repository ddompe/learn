## Why this matters

CSV is perfect for small tables and for exchange. But a table with millions of rows
becomes slow to read and big to store, and every program has to guess the types again.
**Parquet** is a binary format made for analysis of large tables. You will meet it as
soon as you work with big data, or with tools like DuckDB (lesson 6.9).

## Rows and columns

A CSV stores data **row by row**: all the fields of the first sale, then the second.
Parquet stores **column by column**: all the IDs together, then all the amounts.

<Mermaid
	diagram={`flowchart LR
  A["CSV: row 1, row 2, row 3"] --> B["To read one column you must read everything"]
  C["Parquet: column ID, column Monto, column Fecha"] --> D["Read only the columns you need"]`}
/>

Benefits of the columnar layout:

- **Faster reads of a few columns.** An analysis of amounts does not touch names.
- **Smaller files.** Values in a column are alike, so they compress well.
- **Types are stored.** Dates and numbers are not guessed again.

<Example file="part05/09_parquet.py" />

The example repeats the sales data to make a larger table, then writes it both ways. The
Parquet file is smaller. It then reads back only two of the five columns. The last lines
make an honest point: Parquet keeps the types you give it. The `Monto` column here is still text,
because the CSV was messy. Cleaning comes first (Part 6).

## When to use it

| Situation                                 | Use     |
| ----------------------------------------- | ------- |
| Small table, or sharing with anyone       | CSV     |
| A person needs to open and read it        | CSV     |
| Large table, analysed repeatedly          | Parquet |
| You want types to survive between steps   | Parquet |
| You need to see the data in a text editor | CSV     |

A common pattern: receive messy CSV, clean it once, save the clean version as Parquet,
and use that for later analysis.

## Common mistakes

- **Using Parquet for a 50-row table.** CSV is simpler.
- **Writing Parquet from untidy data.** Clean it first.
- **Expecting to open it in a text editor.** It is binary.
- **Sending Parquet to someone without the tools.** Check first.
- **Forgetting the extra dependency.** pandas needs a Parquet engine such as pyarrow.
