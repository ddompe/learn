## Why this matters

You already use TOML: your project's `pyproject.toml` is written in it (lessons 3.8 and
4.3). **TOML** (Tom's Obvious Minimal Language) is a settings format designed to be
unambiguous. It avoids most of the traps of YAML, and it supports comments, which JSON does not.

<CaseStudy>
	Daniela opens the `pyproject.toml` of her report project and wants to read the
	Python version and the dependencies. She does not have to guess what each line
	means.
</CaseStudy>

## The shape of TOML

<Example file="part03/08_pyproject_example.toml" />

- `[project]` is a **table**, a named group of settings.
- `name = "cafe-central-report"` is a key and a value. Strings use quotes.
- `dependencies = [ ... ]` is an **array**. Items are separated by commas.
- Comments start with `#`.
- Numbers, booleans (`true`, `false`), and dates have their own, unquoted forms.

Because strings must be quoted, `no` is just a word with quotes around it. Unquoted words
that are not numbers or booleans are errors, not surprises.

## Reading it in Python

<Example file="part05/05_toml.py" />

Python's standard library includes `tomllib` for reading TOML, so no package is needed.
It reads the file into dictionaries and lists. It cannot write TOML. To change a file, edit
it as text, or use `uv add` for dependencies, which edits it safely.

## Comparing the three

| Feature        | JSON                  | YAML             | TOML            |
| -------------- | --------------------- | ---------------- | --------------- |
| Comments       | No                    | Yes              | Yes             |
| Indentation    | Not significant       | Significant      | Not significant |
| Type surprises | Few                   | Many             | Few             |
| Best for       | Data between programs | Complex settings | Simple settings |

## Hands-on

### Your turn

Add a dependency to the sample by hand: `matplotlib`. What must you watch for?

<Checkpoint question="Show the answer">
Add `"matplotlib>=3.8.0",` as a new quoted item in the array, with a comma after the previous item. A missing comma or quote makes the file invalid. In a real project, prefer `uv add matplotlib`, which also updates the lock file.
</Checkpoint>

## Common mistakes

- **Missing quotes on strings.**
- **Missing commas in arrays.**
- **Editing dependencies by hand without updating the lock file.** Use `uv add`.
- **Confusing a table with an array.** `[project]` is a table, and `[...]` after `=` is an array.
- **Expecting to write TOML with the standard library.** It only reads.
