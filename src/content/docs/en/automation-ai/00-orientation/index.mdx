Part 0 is the orientation. You find out whether this course fits you, which learning path to follow, what automation is and is not, and who Café Central is. You also see how every lesson is laid out, so the rest of the course feels familiar.

There is no installation and no code here. The four lessons take about an hour, and you can skim 0.4 if you are short on time.
