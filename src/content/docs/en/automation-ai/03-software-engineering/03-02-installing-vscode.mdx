## Why this matters

From here on, you will do almost everything in one program: **VS Code**. It is a free
code editor from Microsoft that also holds a terminal, version control, an AI
assistant, and a debugger. Using one tool for all of it means fewer installations,
fewer differences between your screen and the lessons, and fewer places for things to
go wrong.

## Install it

Download VS Code from the official site, [https://code.visualstudio.com](https://code.visualstudio.com). Choose the
version for your system.

<OsTabs>
	<Fragment slot="windows">
		Choose the **User Installer**, which does not need administrator rights. Run
		it and accept the defaults. On the "Select Additional Tasks" step, tick
		**Add to PATH** if offered, and **Add "Open with Code" action to Windows
		Explorer file context menu**.
	</Fragment>
	<Fragment slot="macos">
		Download the macOS version. Open the downloaded file, then drag **Visual
		Studio Code** into the **Applications** folder. Start it from Applications.
	</Fragment>
</OsTabs>

If your company laptop blocks installation, ask IT whether VS Code is available in the
company software portal. Do not look for workarounds.

## Open a folder

VS Code works with **folders**, not single files. A folder holds everything for one
project.

1. Start VS Code.
2. Choose **File**, then **Open Folder**.
3. Select the Café Central folder that you unzipped in lesson 0.3.
4. If VS Code asks whether you trust the authors of the files, choose **Yes, I trust the
   authors** for your own folders. Be careful with folders downloaded from unknown
   sources.

## The four areas

<Mermaid
	diagram={`flowchart LR
  A["Explorer: the files in the folder"] --> B["Editor: the open file"]
  B --> C["Terminal: type commands"]
  D["Extensions: add features"] -.-> B`}
/>

- The **Explorer** (left side) lists the files and folders. Click a file to open it.
- The **editor** (centre) shows and changes the open file.
- The **terminal** (bottom) is the terminal from lesson 1.9. Open it from the **Terminal**
  menu, **New Terminal**. It starts in your project folder, which is very handy.
- **Extensions** (left bar, the four-squares icon) add features. Search by name and
  choose **Install**. Only install extensions from publishers you trust.

Open `cafe_central_sales.csv` from the Explorer. It opens as plain text, and nothing
changes it. That is the safe way to look at a CSV.

### Worked example

1. Open the Café Central folder.
2. Click the sales CSV and scroll to the bottom. How many lines are there? The line
   number appears at the bottom right when you click in the text.
3. Open a terminal inside VS Code and run `pwd` (macOS, or PowerShell) to see that it
   starts in the same folder.

## Common mistakes

- **Opening a single file instead of a folder.** Many features, such as the terminal in
  the right place, work best with a folder.
- **Confusing VS Code with Visual Studio.** They are different products. You want VS Code.
- **Installing many extensions at once.** Add one at a time and only when needed.
- **Editing the original data.** Make a copy of the data folder before experimenting.
- **Ignoring the trust prompt.** It exists for a reason. Trust only folders you know.
