## Why this matters

Writing Python is useful only if you can run it. There are three common ways, each
for a different job. Knowing which to use saves you from copying code between tools and
wondering why the results differ.

<CaseStudy>
	Daniela wants to test how Python adds three sale amounts. She tries it in the
	REPL, then saves the idea as a script that she can run every month.
</CaseStudy>

## The REPL

The **REPL** (read, evaluate, print, loop) is an interactive prompt. You type a line,
Python runs it, and shows the result. It is a calculator for code.

```text
uv run python
```

The prompt changes to `>>>`. Try:

```text
>>> 2200 + 1500 + 1400
5100
>>> exit()
```

Use the REPL to try a small idea. Nothing is saved when you leave.

## Running a script

A **script** is a Python file that you run from start to finish. Here is the first one:

<Example file="part04/04_hello.py" />

From the project folder, run:

```text
uv run python 04_hello.py
```

`uv run` makes sure that the program runs inside the project's environment (lesson 4.3), with
the right Python and packages. Always start programs with `uv run`.

## Running in VS Code

1. Install the **Python** extension (from the Microsoft publisher) in VS Code.
2. Open the file. If VS Code asks for an interpreter, choose the one in `.venv` inside your project.
3. Click the **Run** triangle at the top right of the editor. The output appears in the terminal below.

The Run button does what the terminal command does. Use either, and notice that both
show the same output. If they differ, one of them is using a different environment.

## Common mistakes

- **Running `python` instead of `uv run python`.** The wrong Python may start.
- **Running from the wrong folder.** The file name is relative to the current folder.
- **Editing a file and forgetting to save.** The old version runs.
- **Typing code lines starting with `>>>`.** Those are the prompt, not part of the code.
- **Expecting the REPL to remember.** Closing it forgets everything.
