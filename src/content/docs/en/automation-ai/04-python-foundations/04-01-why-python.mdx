## Why this matters

You will spend the rest of the course writing and reading Python. It helps to know why we
chose it, so that it does not feel like an arbitrary rule. It also helps in conversations
with colleagues who prefer other tools.

<CaseStudy>
	Daniela's team has Excel, Power Query, and some macros. When she needs to
	combine hundreds of files, or call an AI service, those tools run out of road.
	Python is the tool that most people in her position pick up next.
</CaseStudy>

## A short history

Guido van Rossum started Python in the late 1980s, and released it in 1991. He designed it
to be easy to read, and to let a person say a lot in few lines. The name comes from the
comedy group Monty Python, not the snake.

Since then, three things made it the default for data work:

1. **Readability.** Python code looks close to plain English. A beginner can read a
   short program and guess what it does.
2. **Batteries included.** The standard library covers files, dates, text, CSV, and
   much more without extra downloads.
3. **A huge ecosystem.** Thousands of free packages exist for data (pandas), charts
   (matplotlib), documents, the web, and machine learning. Almost every AI tool offers a
   Python interface first.

## Why it matters for AI

Most AI libraries and services are written for Python first, and most examples that you
find online are in Python. AI assistants have also seen far more Python than most
languages, so they write it well. This is a practical reason: you get the best help.

## Trade-offs

Python is not the best at everything.

- **Speed.** Python is slower than languages like C or Rust for heavy computing. Libraries
  hide this by doing the heavy work in fast code underneath. For business data, it is
  rarely a problem.
- **Mobile and web front ends.** Other languages dominate there.
- **Versions and installs.** Setting up Python badly causes many headaches. That is why
  lesson 4.2 uses uv.

## Common mistakes

- **Treating Python as the only option.** It is a good default, not a law.
- **Comparing speeds without context.** For a monthly report, a second more or less does
  not matter.
- **Starting without a clear setup.** Lesson 4.2 prevents the typical problems.
- **Thinking you must memorise syntax.** You will read far more than you write.
