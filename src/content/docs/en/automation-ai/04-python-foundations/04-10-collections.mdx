## Why this matters

Business data comes in groups: rows, columns, customers, categories. A **collection**
holds many values in one variable. Each kind of collection suits a different job, and
choosing the right one makes the code short and clear.

<CaseStudy>
	Daniela wants to count sales per category and know how many distinct customers
	bought anything. A dictionary does the first, and a set does the second.
</CaseStudy>

## The four collections

| Collection | Written as       | Key idea                        | Example use                         |
| ---------- | ---------------- | ------------------------------- | ----------------------------------- |
| List       | `[a, b, c]`      | Ordered, can change, can repeat | The rows of a file                  |
| Dictionary | `{"key": value}` | Look up a value by its key      | Count per category                  |
| Tuple      | `(a, b)`         | Ordered, cannot change          | A fixed pair, like an ID and amount |
| Set        | `{a, b, c}`      | No repeats, no order            | Distinct customers                  |

## In action

<Example file="part04/10_collections.py" />

- `rows[:3]` takes the first three items of a list. Counting starts at zero: `rows[0]` is
  the first one.
- The dictionary `counts` maps each category, as written, to how many times it appears.
  `counts.get(key, 0)` returns zero for a key not seen yet.
- The set comprehension `{row[2] for row in rows if row[2]}` collects customers,
  ignoring blanks and repeats. There are 8 distinct customers.

The count also shows the mess in the categories: `café` appears 36 times, but `Café` 3 and
`cafe` 4 times separately. Lesson 4.9's `simplify` merges them.

## Common mistakes

- **Starting to count at 1.** Positions start at 0.
- **Changing a list while looping through it.** Build a new one instead (lesson 4.11).
- **Expecting order from a set.** Sets have no order.
- **Using a list to look things up.** A dictionary is far quicker and clearer.
- **Forgetting that a key must exist.** Use `.get()` with a default.
