## Why this matters

Automation is mostly two ideas: do something for every item, and do different things
depending on the item. In Excel, these are fill-down and `IF`. In Python, they are `for`
and `if`. With these two, and the collections from lesson 4.10, you can process a whole file.

<CaseStudy>
	Daniela wants to label each sale as small, medium, or large, and to know how
	many sales it takes to pass a daily target.
</CaseStudy>

## Decisions: if

```text
if amount >= 5000:
    label = "large"
elif amount >= 1500:
    label = "medium"
else:
    label = "small"
```

Python checks the conditions in order and runs the first block that is true. The lines
inside a block are **indented** (moved right by four spaces). Indentation is how Python
knows what belongs to what, so it matters.

Comparisons give a boolean: `==` equal, `!=` not equal, `<`, `>`, `<=`, `>=`. Combine them
with `and`, `or`, and `not`.

## Repeating: for and while

A `for` loop repeats once for each item in a collection. A `while` loop repeats as
long as a condition stays true.

<Example file="part04/11_control_flow.py" />

The `for` loop visits each amount and decides its label. The `while` loop keeps adding sales
to a running total until it passes 5000. It stops after 3 sales, at 5100.

<Mermaid
	diagram={`flowchart TD
  A["Start: running = 0"] --> B{"running < 5000?"}
  B -- Yes --> C["Add the next amount"]
  C --> B
  B -- No --> D["Stop"]`}
/>

A `while` loop needs something inside it that eventually makes the condition false. If not,
it runs forever. Stop a program that runs away with **Ctrl+C** in the terminal.

## Common mistakes

- **Wrong indentation.** A line indented too much or too little changes the meaning.
- **Using `=` instead of `==` in a condition.** One assigns, and the other compares.
- **Changing a list while looping over it.** Make a new list instead.
- **A `while` loop that never ends.** Make sure the condition can become false.
- **Checking conditions in the wrong order.** In `if`/`elif`, put the narrowest condition first.
