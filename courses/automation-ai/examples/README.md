# Examples for Automation & AI for Business Users

This directory contains runnable Python examples used in the course lessons. Each lesson or set of lessons has a corresponding `part-XX/` subdirectory with:

- `*.py` - example scripts demonstrating the concept
- `test_*.py` - pytest tests validating the example

## Running examples

From this directory, run all tests with:

```sh
uv run pytest
```

Or run a specific test:

```sh
uv run pytest test_filename.py
```

## Example outputs

The `__outputs__/` directory contains expected outputs from running the examples. These are regenerated automatically by `scripts/run_examples.py` (see the repo root's `scripts/` directory).

## Data

The `data/` directory contains datasets used by examples, such as the messy Café Central case-study data. These are generated by `scripts/generate_dataset.py`.
