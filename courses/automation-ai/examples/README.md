# Examples for Automation & AI for Business Users

This directory contains runnable Python examples used in the course lessons. Examples live in `partPP/` subdirectories (for example `part00/`), named `LL_slug.py` per lesson:

- `*.py` - example scripts demonstrating the concept
- `test_*.py` - pytest tests validating the example

`repo_scripts.py` lets tests import the build scripts in the repo's `scripts/` directory.

## Running examples

From this directory, run all tests with:

```sh
uv run pytest
```

Or run a specific test:

```sh
uv run pytest test_filename.py
```

## Example outputs

The `__outputs__/` directory contains expected outputs from running the examples. These are regenerated automatically by `scripts/run_examples.py` (see the repo root's `scripts/` directory).

## Data

The `data/` directory contains datasets used by examples, such as the messy Café Central case-study data (CSV and JSON for lesson 0.3, plus an Excel summary and a PDF invoice for Part 5, shipped as a second zip). These are generated by `scripts/generate_dataset.py` (seeded, reproducible) and packaged for download by `scripts/package_datasets.py` into `public/downloads/automation-ai/cafe-central-data.zip`. After changing the generator, rerun both and commit the results; a test fails if the committed files or zip are stale.
