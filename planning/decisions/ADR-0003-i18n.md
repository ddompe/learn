# ADR-0003: English source, Spanish second, mirrored trees

- Status: Accepted
- Date: 2026-10-03

## Context

The course must be multi-language. Writing two languages in parallel slows content development and causes drift.

## Decision

English is the source of truth. Spanish lives in a mirrored directory tree with identical slugs, translated per part once the English part is stable. Each translation records the source hash for staleness detection.

## Consequences

English ships first. Spanish lags by about one milestone. Untranslated pages fall back to English. Code and identifiers remain in English in both locales.
