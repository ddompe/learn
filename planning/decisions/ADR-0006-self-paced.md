# ADR-0006: Self-paced, no auto-graded exercises

- Status: Accepted
- Date: 2026-10-03

## Context

Auto-grading requires significant engineering (in-browser execution, test harnesses) and does not suit all exercise types.

## Decision

The course is self-paced. Self-check questions use collapsible answers; each part ends with a self-verified project checklist.

## Consequences

Lower implementation cost; no accounts or backend. In-browser Python (Pyodide) remains an optional later enhancement.
