# ADR-0007: CC BY-SA 4.0 for content, MIT for code

- Status: Accepted
- Date: 2026-10-03

## Context

We want the content reusable and translatable by others, while keeping derivatives open, and the code freely usable.

## Decision

Lesson content is licensed CC BY-SA 4.0 (LICENSE-CONTENT). Code in examples/, scripts/, and site source is licensed MIT (LICENSE).

## Consequences

Encourages community translations and reuse in classrooms. The site footer and README state both licenses clearly.
