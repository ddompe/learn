# ADR-0008: GitHub Sponsors for donations

- Status: Accepted
- Date: 2026-10-03

## Context

Diego would like an optional way for learners to support the project, like a buy-me-a-coffee link.

## Decision

Use GitHub Sponsors: FUNDING.yml in the repo and a coffee-styled button in the site footer linking to the Sponsors page.

## Consequences

GitHub Sponsors is already set up on Diego's personal account, so the repo should live under the personal account (or FUNDING.yml must point to it). No extra payment platform needed.
