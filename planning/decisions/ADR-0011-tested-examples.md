# ADR-0011: Code shown in lessons comes from tested files

- Status: Accepted
- Date: 2026-10-03

## Context

Code in tutorials rots silently when libraries change. Starlight does not execute code.

## Decision

All Python shown in lessons lives in examples/, a uv project with pytest tests. Outputs are generated by a script and checked for freshness in CI. Lessons import code and output via ?raw.

## Consequences

Documented code and outputs always match reality. Slightly more friction when writing lessons. Examples that call paid APIs (Part 10) need mocks or recorded responses.
